# Astra's PullMod Hub

Astra's PullMod Hub is a collection of different pull mod systems, older pull methods, newer systems, and experimental movement ideas all built into one mod.

The goal of the Hub is to let you quickly switch between different pull behaviors, compare them, customize them, and save your favorite setups as presets.

This includes methods based on Astra's PullMod V1, Astra's PullMod V2, older pull styles, and multiple experimental methods.

## Features

- Multiple pull methods
- Custom pull settings
- Adjustable pull power
- Adjustable uphill power
- Momentum control
- Maximum pull control
- Velocity clamping
- Adjustable maximum velocity
- Extra power control for experimental methods
- Multiple activation modes
- Left, Right, or Both hand modes
- Custom controller input selection
- Preset saving
- Preset loading
- Preset deletion
- Tabbed UI

## Pull Methods

### PMV1

Classic Astra's PullMod V1 style pull behavior.

### PMV2

Momentum-based pull behavior based on Astra's PullMod V2.

### Regular

A more traditional pull method using velocity and forward movement.

### Gravity

Pull movement with extra upward assistance.

### Surface

Projects movement along the surface below the player.

### Burst

Adds a short velocity burst based on current movement.

### Inertia

Adds extra momentum directly into the player's velocity.

### Elastic

Uses speed-based scaling to create a more elastic pull feel.

### Directional

Pull strength changes depending on how closely your movement matches the direction you are facing.

### Curve

Uses non-linear speed scaling to change pull strength.

### Air Pull

Designed to be stronger while the player is not touching a surface.

### Ground Pull

Designed to be stronger while the player is touching a surface.

## Inputs

The Hub supports multiple controller inputs including:

- Grip
- Trigger
- Joystick Click
- A
- B
- X
- Y

Input behavior can also be changed between:

- Both Hands
- Left Hand
- Right Hand

## Activation Modes

### Release

Activates the pull for a short period after releasing your hand from a surface.

### Touch

Activates while touching a surface and can use a small touch linger window.

### Hold

Continuously applies the selected pull method while the selected input is held.

## Presets

The Hub includes a custom preset system.

Presets can save settings such as:

- Selected pull method
- Pull power
- Uphill power
- Momentum
- Max pull
- Max velocity
- Extra power
- Velocity clamp
- Input
- Hand mode
- Activation mode
- Release window
- Touch linger

Saved presets can be loaded or deleted from the Presets tab.

## Menu

## Controls

`P` - Open / Close Astra's PullMod Hub

## Installation

1. Install BepInEx for Gorilla Tag.
2. Download the latest Astra's PullMod Hub release.
3. Put the DLL inside your BepInEx `plugins` folder.
4. Start Gorilla Tag.
5. Press `P` to open the menu.

## About

Astra's PullMod Hub is mainly meant to be a place for experimenting with pull systems.

Some methods are based on older pull styles while others are new experimental ideas.

More methods and settings may be added over time.
